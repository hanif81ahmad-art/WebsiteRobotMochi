Dashboard Mochi

Halaman GitHub ini adalah pintu masuk. Untuk mengirim perintah tanpa Firebase, kontrol harus dibuka dari web server ESP32 di jaringan lokal.

Tanpa Firebase · Tanpa cloud relay

Jika memakai Wi-Fi rumah, alamat IP tampil di Serial Monitor Arduino IDE setelah ESP32 tersambung. HP dan ESP32 harus berada di jaringan yang sama. Jika memakai Wi-Fi langsung, sambungkan HP ke Dasai-Mochi terlebih dahulu, lalu buka http://192.168.4.1.

Catatan browser: GitHub Pages memakai HTTPS, sedangkan ESP32 lokal memakai HTTP. Karena batasan keamanan browser, halaman GitHub tidak bisa mengendalikan endpoint HTTP ESP32 secara langsung dengan andal. Tombol di sini membuka dashboard lokal ESP32 yang melakukan kontrol langsung.
